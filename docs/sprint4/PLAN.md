# Спринт 4 — Урок 20 минут и независимая оценка

**Цель:** ученик проходит настоящий урок из своего плана — пять этапов «повторение → объяснение → ролевая ситуация → проверка без подсказок → итоги» — с паузой и восстановлением, разыгрывает сценарии и упражнения к медиа из «Практики», получает независимую оценку по рубрике с 1–3 доказанными ошибками и может её оспорить. Навыки на карте меняются только по оценке. Занятия засчитываются в график, серию и пропуски по реальным урокам. В админке появляются «Агенты и скиллы» (версии инструкций, золотые тесты, публикация и канарейка, маршрутизация моделей), «Контроль диалогов» (журнал сессий, карточка оценки, переоценка, апелляции, постановка задачи) и «Затраты и лимиты».

Требования (LinguaFlow 1.2): APP-LESS-01…09, APP-COACH-01 (частично: режимы урок/практика), APP-COACH-02…05, APP-VOICE-03 (текстовый режим — основной), APP-MEDIA-02, APP-PROG-03 (частично: история уроков), ADM-AGENT-01…05, ADM-QA-01…04, ADM-MONEY-01, ADM-MONEY-02 (лимиты ИИ). Скиллы: `learning_orchestrator` (код lessons), `teaching_coach`, `conversation_partner`, `independent_evaluator` (LLM через ai-gateway), `error_analyst` (часть вывода оценщика), `safety_quality_gate` (правила в ai-gateway). Голос (APP-VOICE-01/02, ASR) — за флагом `voice.asr` (выключен, реализация — после технического допуска WebRTC); озвучка реплик — синтез речи устройства, как в спринте 3.

## Решения владельца (19.11.2026)
- Провайдер ИИ — **Anthropic Claude**. Ключ `ANTHROPIC_API_KEY` владелец вводит в Railway (только у ai-gateway). Без ключа ИИ выключен, урок проходится полностью: ролевая ситуация — выбором реплик, оценка — закрытых заданий.
- Потолок расходов на ИИ в prod до спринта 8 — **$20 в месяц**; на ученика — не больше **$0,05 в день**. При достижении — урок продолжается без ИИ (тот же сценарий выбором реплик), ученик видит нейтральное «сейчас занятие идёт в упрощённом режиме».
- Дети 6–13 — **без свободного текста к ИИ**: только готовые варианты реплик; их ответы в ИИ не отправляются (ai-gateway отклоняет вызов с аудиторией kids для агентов свободного текста).

## Решения
- **Оркестратор — код, не LLM.** lessons ведёт машину состояний и порядок этапов по опубликованному уроку; LLM-агенты вызываются только через ai-gateway и только с нужными данными (AgentContext без истории сверх текущей сцены).
- **Ролевая ситуация идёт по графу сценария.** Свободный текст ученика `conversation_partner` относит к одному из разрешённых переходов текущего узла (или `unclear`) и даёт естественную реплику персонажа в рамках узла; переход и конец сценария определяет граф. Поэтому сценарий детерминированно завершается исходом успех / тоже хорошо / не вышло, а без ИИ работает тем же графом выбором реплик.
- **Оценщик независим.** assessment сам берёт ключи и рубрику из опубликованной версии catalog по зафиксированным в сессии версиям, не доверяет оценкам lessons и словам коуча; оценки неизменяемы, переоценка — новая запись со ссылкой на исходную.
- **Навыки:** «демонстрирует» — только по проверке без подсказок (≥ 2/3 заданий навыка верно) при выполненном правиле рубрики; иначе «изучается». «Закреплён» — спринт 5 (отсроченная проверка). Владелец карты навыков — diagnostics (как в спринте 3), оценки приходят событием.
- **Модели по умолчанию:** диалог и объяснение — `claude-haiku-5-5`, оценщик — `claude-sonnet-5-5`; резервная — Haiku. Цены — таблица в ai-gateway, правится в админке (`ai.publish`), значения по умолчанию сверены с прайсом Anthropic на 19.11.2026 ($0,10/$0,50 и $2/$10 за 1 млн токенов).
- **Хранение реплик:** свободный текст ученика хранится в lessons 90 дней (затем текст стирается, оценка и доказательства-цитаты ≤ 120 символов остаются в assessment); в ai-gateway — только метаданные вызова (без текста). Удаление ученика — сага.
- **Ручная активность Mini App** (спринт 1, «практика») больше не используется: занятия приходят событиями lessons; эндпоинт оставлен для совместимости.
- **Голос:** ASR и потоковый голос — за флагом (выключен), не реализуются в спринте; речь в уроке — текстом (APP-VOICE-03), произношение не оценивается (`pronunciation: null`).
- **Награды** (XP, монеты) — спринт 6; в карточке урока награда не показывается.

## Definition of Done
Тесты сервисов на стенде, ruff/mypy/tsc чистые, Playwright Mini App и admin-web на mock BFF, сквозной e2e на живом стенде в двух режимах (fake-провайдер ИИ и ИИ выключен): урок целиком с паузой и обрывом, ролевая ситуация выбором и свободным текстом, оценка и итоги, апелляция → переоценка → уведомление, практика сценария и медиа, ребёнок, агент — черновик → тесты → публикация → канарейка → откат, бюджет → упрощённый режим; независимое ревью без 🔴, QA-отчёт `docs/qa/sprint4-qa-report.md`, PR, деплой Railway (ai-gateway, lessons, assessment + обновлённые сервисы), инструкции агентов в prod; ключ Anthropic — владельцем.
