# Спринт 2 — Админка: вход сотрудников, ученики, «Что нового», шаблоны уведомлений и рассылки

**Цель:** сотрудники входят в веб-админку (пароль + TOTP), видят меню по своим правам, находят ученика и его детей без лишних персональных данных, отвечают в поддержке, сами управляют «Что нового» (черновик → предпросмотр RU/UZ → публикация с повторным TOTP → архив, статистика показов), текстами уведомлений и рассылками по сегментам с экстренной остановкой, откатывают тему Mini App и админки без сборки. Каждое привилегированное действие — в аудите.

Основа — админ-контур «Бот турист» (aievent, спринты 2–9): admin-identity, user-admin, admin-bff, admin-web и `packages/contracts/src/admin.ts` переносятся и сокращаются до объёма TilHero. Визуальный язык — согласованный прототип `/home/claude/lf/project/Admin.dc.html` (тетрадь, тёмная боковая панель, меню из 15 разделов).

## Решения
- admin-bff без публичного домена: admin-web (Caddy) проксирует `/admin/v1/*` → один origin, cookie first-party (как aievent).
- Первый администратор — через `ADMIN_BOOTSTRAP_EMAIL/PASSWORD` (только при пустой таблице super_admin), затем переменные удаляются.
- Шаблоны уведомлений: код — источник текстов по умолчанию; администратор создаёт версию поверх (RU и UZ обязательны, только плейсхолдеры шаблона); активная версия применяется при отрисовке; откат — к любой версии или к тексту по умолчанию. Детские шаблоны (`*.kid`) правятся отдельно и проходят проверку «без давления».
- Рассылки — только категория `product` (новости TilHero): согласие `product_news` и категория включены, политика доставки та же (тихие часы, лимиты, дедупликация), детские профили исключены всегда, подростки — только если в сегменте явно указаны 14–17. Частота — не чаще 1 рассылки в 7 дней на ученика (настройка). Аудиторию отбирает identity-consent (`/internal/v1/audience`), notifications создаёт записи пачками.
- Тестовые получатели — `ADMIN_TEST_CHAT_IDS` (Telegram chat id через запятую) в notifications; других адресатов тестовая отправка не принимает.
- Разделы меню без функций спринта 2 (контент, агенты, качество, затраты, герои, игра, события, языки) — честный экран «скоро» с номером спринта.
