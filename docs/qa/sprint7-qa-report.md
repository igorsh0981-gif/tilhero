# Спринт 7 «Социальное» — QA-отчёт

**Вердикт: PASS.** Повторное и финальное ревью без 🔴, сквозной сценарий social 14/14 на пересозданных схемах (2483 проверки).

## Решения владельца (21.11.2026)
- Общая лига — с 14 лет, по желанию, видно только ник; 14–17 — с согласием родителя.
- Уроки вдвоём — полностью в спринте 7 (минуты считаются, списание — спринт 8).
- Рефералы: награда после диагностики и 3 уроков за 2 разных дня.
- Приглашения (урок вдвоём, напоминание о нём, вызов на дуэль) — вне общего лимита 3 Telegram-сообщений в сутки.

## Решения координатора (стоит подтвердить)
| Решение | Почему |
|---|---|
| Рефералы спринта 6: невыданные награды доживают по старому правилу (первый урок, 90 дней); уже награждённым повторной награды нет; месячный лимит считает награды обоих правил | ревью: двойная награда и потеря обещанной при переходе |
| Перенесённые рефералы: диагностика засчитана, окно «3 урока за 2 дня» — от выкладки, тихое истечение без «окно истекло» | истории активности до спринта 7 нет |
| Один месячный лимит рефералов — из кампании (`inviter_monthly_cap` в событии); правило игры — только для доживающих | ревью: два лимита противоречили |
| Урок вдвоём: XP и значок «Вместе» — только за урок, доведённый до цели, и ≥ 1 свой ход; не больше 3 награждаемых уроков в сутки | ревью: фарм XP через брошенные комнаты; порог 3 хода делал значок недостижимым |
| ИИ-коуч — не больше 5 комнат на ученика в сутки, дальше — выбор реплик | ~200 комнат съедали месячный бюджет ИИ всех учеников |
| Сброс ника модератором: сброшенный ник запрещён всем, новый — через 7 дней; снятие санкции снимает запрет | ревью: тот же ник ставился сразу |
| Код друга сотрудникам — маской, полностью только с `moderation.manage` | ревью: код виден всем ролям с `social.read` |
| Лимит приглашений против спама: 5 в сутки получателю, 2 от одного отправителя | приглашения вышли из общего лимита |
| Детская заметка «Что нового» — отдельная иллюстрация `s7-family` без пьедестала | детям мест и сравнений не показываем |

## Ревью
- **Бэкенд, первое — отклонено (3 🔴):** сага удаления в lessons восстанавливала данные удалённого; переход рефералов спринта 6 давал двойную награду и терял обещанную; проекции gamification без начальной загрузки (пустые лиги семьи и друзей, все в A0–A1). 🟡: удалённый в наградах, сброс ника, одобрение отказа «семья», «не новый ученик», фарм XP и бюджет ИИ, согласие 14–17 только в BFF, long-poll ждал коуча. 🟢 ×11.
- **Бэкенд, повторное — отклонено (1 🔴):** подростки с давним согласием родителя не попадали в общую лигу. 🟡: окно дожития 30 вместо 90 дней, два месячных лимита, порог 3 хода. 🟢 ×5.
- **Бэкенд, финальное — согласовано.**
- **Фронтенд, первое — не принимать (1 🔴):** назначенный урок вдвоём — бесконечная загрузка. 🟡: «мёртвая» комната, связь в фоне, выход после ухода с экрана, ключ хода, жалоба в комнате, красные тесты иллюстраций, пьедестал в детской заметке, повтор переоценки лиги. 🟢 ×11.
- **Фронтенд, повторное — мерж возможен;** оставшиеся 🟢 (F7-14, 16, 21, 22, 23) тоже закрыты.
- **e2e:** миграции, правленные на месте, на стенде (схемы пересозданы), learning-plan не принимал `kind duel|pair`, identity-consent не пускал lessons к `/public` (голос в комнате не работал бы), 404 карточки неизвестного ученика; admin-bff срезал `min_turns` и `daily_cap` в правилах урока вдвоём — правила игры не сохранялись через админку. Всё исправлено.

## Вопрос владельцу
- Со спринта 7 категория «Игра» включена по умолчанию, поэтому «Серия спасена» (день закрыт заморозкой) уходит в Telegram сразу, а на следующий день в слот — «Вчера занятия не было». Сообщения звучат противоречиво; можно не отправлять «Вчера занятия не было», если день закрыт заморозкой.

## Известные ограничения
- Цель согласия `social` gamification сам не проверяет (событие отзыва не несёт целей) — проверка в telegram-bff.
- Сценарии уроков вдвоём без английских `title/task/role/criteria`: lessons собирает английское описание для коуча из id и реплик; стоит добавить поля в контент.
- Fake-коуч на стенде не завершает комнату — цель в e2e достигается через переход на выбор реплик.
- Тексты UZ (Mini App, шаблоны, стоп-лист ников) — черновики на вычитку.
- Оплата минут уроков вдвоём и тилов — спринт 8.
- Публикация `cooperative_lesson_coach` v1 (после golden-тестов) — владелец, в админке «ИИ».
