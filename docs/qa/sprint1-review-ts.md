## Проверено — замечаний нет
- **Сессия и lrn.** В access JWT `sub` — аккаунт, `lrn` — ученик. На каждом запросе проверяется, что сессия жива и её `lrn` в Redis совпадает с токеном: после переключения ученика старый токен получает 401 `TOKEN_EXPIRED {reason: learner_switched}`. `reissue` удаляет прежний refresh. Ротация refresh с обнаружением повторного использования. Отзыв всех сессий при смене или сбросе кода и при удалении.
- **Переключение на чужого ребёнка.** BFF сверяет ответ identity `GET /me/learners/{id}` (с `sub` аккаунта) с запросом (`id`, `kind=child`, есть в списке учеников) → 404 `LEARNER_NOT_FOUND`. Выход из детского профиля при заданном коде требует `pin` (лимит `tg.pin`).
- **Субъект внутреннего JWT по маршрутам.** learning-plan, центр уведомлений и experience-config получают `lrn`. identity `/me/*`, social и support получают аккаунт. Покрыто тестом `subjects.test.ts`.
- **Запреты в детском профиле по §10.** Приглашения (все) → 403 `INVITES_NOT_ALLOWED`. Создание детей, решение по согласию подростка, код родителя, биометрия, удаление аккаунта и поддержка → 403 `ADULT_REQUIRED`; домены при этом не вызываются.
- **initData.** HMAC сравнивается за постоянное время, `auth_date` не старше 600 с и не из будущего, initData одноразовый (Redis, при сбое отказ), лимит 10/мин с IP. `start_param` отдаётся только при формате `[A-Za-z0-9_-]{1,64}`.
- **Логи BFF.** В access-логе шаблон маршрута (токены `gc_` в пути не попадают), redact-пути и рекурсивная вычистка ключей (`link`, `start_param`, имена, токены).
- **Ответы доменов фильтруются по белому списку** (`views.ts`). Значения перечислений вне контракта приводятся к безопасным.
- **Mini App.** Access-токен хранится только в памяти, refresh — в `sessionStorage` с привязкой к запуску (новый запуск в той же вкладке не продолжает старую сессию и не обходит код родителя). Обновление токена выполняется одним запросом за раз и согласовано с выдачей новых токенов (код родителя, переключение ученика). Глубокие ссылки разбираются по белому списку. В детском профиле скрыты семья, поддержка, данные и удаление, секция «Семья» на главной. Детские тексты без давления.
- **«Что нового».** Показ один раз на ученика за сеанс. Просмотренными отмечаются только заметки, чьи карточки были на экране. Режим updates управляется флагом `whats_new_on_login`; по умолчанию он `true`, во встроенной конфигурации — тоже `true`.
