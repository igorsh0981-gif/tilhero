# Релиз 5.1 — QA-заметка (оценка произношения на своём сервере)

**Причина.** Регистрация Azure Speech не прошла. Решение владельца (20.11.2026): распознавание на своём сервере, политика 1.2.

## Что изменилось
- **tts:** `POST /internal/v1/recognize` (только ai-gateway) — faster-whisper `base.en`, int8, VAD, слова с вероятностями и временем. Очередь `ASR_CONCURRENCY`, таймаут 10 с, после таймаута новое распознавание ждёт окончания прежнего. Модель — в образе по закреплённому коммиту, рантайм офлайн.
- **ai-gateway:** провайдер `whisper` по умолчанию; выравнивание слов эталона Левенштейном, числа словами; accuracy, fluency (паузы, темп), completeness, pron; `insufficient_evidence` при пустом или неуверенном распознавании. Стоимость 0, бюджеты не тратятся, аварийная остановка действует. Azure остаётся запасным провайдером.
- **identity-consent:** политика 1.2; голосовое согласие засчитывается с 1.1.
- **admin-bff / admin-web:** провайдер `whisper`, модель `whisper-base-en` за $0, цена часа не редактируется (ai-gateway: 422 `PRICE_NOT_APPLICABLE`).
