## Решения координатора (стоит подтвердить)
| Решение | Почему |
|---|---|
| Ступень героя растёт только за навыки, подтверждённые уроком или проверкой удержания; отметки первичной диагностики не считаются | иначе сильный ученик получал ступень 2–3 сразу после теста |
| Игровые уведомления при выключенных «Напоминаниях» остаются в центре без Telegram | по умолчанию напоминания выключены, «Серия спасена» иначе терялась |
| Уведомления о значках и росте героя по событиям старше 60 минут не отправляются | первая выкладка обработает историю за 7 дней |
| Ручное начисление заморозок — не больше 100 за операцию; бонусы запасом 5 не ограничены | ревью: freeze_left > 30 ломал событие |
