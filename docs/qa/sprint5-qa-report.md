## Решения владельца в спринте
- **Произношение — Azure.** Детям — только с согласия родителя. Перевод по тапу: словарь курса, затем ИИ.
- **Политика согласия 1.1.** Цель `voice_recording` — «Оценка произношения по записи голоса», звук не хранится. Каждый пользователь один раз подтверждает согласие заново.
- **Подлимит речи** — $5 в месяц.

## Известные ограничения
- **Нестабильные TS-тесты** (`content.test.ts`, `plan.test.ts` в telegram-bff; AT-29 в admin-web) — падают только при параллельной нагрузке на общий Redis стенда, при повторе проходят.
- **fake-оценщик** выдаёт `error_code` вне закрытого списка (`missing_to`, `extra_be`). memory сохраняет их как `other`. Касается только стенда.
