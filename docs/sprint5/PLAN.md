# Спринт 5 — Память и повторения

**Цель.** Слова, фразы и ошибки из уроков, чтения и медиа попадают в личный словарь ученика и в интервальные повторения (FSRS). Каждый день ученик проходит короткое «Повторение дня»: узнавание, а затем самостоятельное воспроизведение — выбор готового ответа не считается самостоятельной фразой. Через 7 и 30 дней после «демонстрирует» навык проходит отсроченную проверку без подсказок. Только после успешной проверки на 30-й день навык становится «закреплён».

Остальное в спринте:
- **Чтение.** Короткие тексты по уровню с переводом слова по тапу (словарь курса, затем ИИ с кешем) и вопросами на понимание.
- **Произношение.** Ученик читает фразу в микрофон, Azure Speech оценивает каждое слово. Звук не хранится. Дети — только с согласия родителя на запись голоса.
- **Напоминание.** Раз в день вечером: «N слов на повторение».
- **Админка.** «Словарь курса» и модерация переводов ИИ, тексты для чтения в «Контенте», «Память и повторения» (очереди, история планирования, ручная правка с аудитом), аналитика забывания, затраты на произношение.

Требования LinguaFlow 1.2:
- APP-MEM-01…05 (журнал ошибок, словарь, активное воспроизведение, FSRS, проверка удержания);
- APP-ADV-01 (произношение по реальной акустике);
- APP-VOICE-04 (разрешение микрофона по потребности), APP-VOICE-03 (текстовый резерв);
- APP-PROG-02 (частично: словарь и чтение в отчёте по навыкам), APP-PROG-04 (частично: сохранённые фразы);
- ADM-MEM-01, ADM-MEM-02.

Скиллы:
- `spaced_repetition_coach` — код memory, правила оценки ответа, FSRS;
- `pronunciation_coach` — акустическая оценка провайдера плюс правила советов, код;
- `teaching_coach` — новая версия с запросом `gloss_word` для перевода слова, которого нет в словаре курса.

«Кино и музыка», часть спринта 5: фразы из медиафрагментов попадают в словарь с аудиоконтекстом.

## Решения владельца (20.11.2026)
- **Произношение — Azure AI Speech, Pronunciation Assessment.**
  - Ключ и регион владелец вводит в Railway как общие переменные проекта `AZURE_SPEECH_KEY`, `AZURE_SPEECH_REGION`. Ссылки на них есть только у ai-gateway.
  - Цена по умолчанию — $1,32 за час аудио (тариф Azure на оценку произношения в реальном времени, ноябрь 2026), правится в админке. Бесплатный уровень Azure F0 — 5 часов в месяц.
  - Без ключа функция скрыта: кнопки «Произнести» нет, урок и повторения идут без неё.
- **Подлимит речи $5 в месяц** внутри общего лимита ИИ $20 (решение после ревью): исчерпан — скрывается только «Произнести», ИИ уроков и оценка не страдают; правится в админке («Затраты ИИ → Лимиты», step-up).
- **Дети 6–13 — микрофон только с согласия родителя** на цель `voice_recording`: в согласии детского профиля, родитель включает в карточке ребёнка.
  - Подростки 14–17 и взрослые — со своим согласием на `voice_recording`; его можно дать в настройках.
  - Аудио не хранится ни у нас, ни у провайдера: обработка «на лету», хранятся только баллы по словам.
- **Перевод по тапу.** Сначала словарь курса (переводы методиста). Слово из нашего контента, которого там нет, переводит `teaching_coach` (Claude Haiku) с общим кешем.
  - Переводы ИИ помечены и видны методисту для подтверждения или исправления.
  - Расходы — из лимита ИИ ($20 в месяц, $0,05 на ученика в день).
  - Переводится только слово, реально встречающееся в опубликованном контенте: произвольный текст ученика в ИИ не уходит, детям тоже.

## Права и роли (дополнение к спринтам 2–4)
- **Новые права:**
  - `memory.read` — очередь, карточки, история планирования ученика, аналитика забывания;
  - `memory.manage` — ручная правка карточки (перенос срока, сброс, заморозка) со step-up и аудитом; массовые правки запрещены;
  - `glossary.manage` — словарь курса и модерация переводов ИИ. Без step-up: правка статьи действует сразу, каждая правка в истории статьи и в аудите. Статьи из ключевых слов уроков, фраз медиа и глоссариев текстов правятся через версию этого контента; в словаре их можно только переопределить.
- **Тексты для чтения** — существующими правами контента (`content.edit` / `content.review` / `content.publish`).
- **Роли:**
  - `methodist` — + memory.read, glossary.manage;
  - `content_manager` — + glossary.manage;
  - `qa_analyst`, `analyst` — + memory.read;
  - `operations` — + memory.read, memory.manage;
  - `auditor` — + memory.read;
  - super_admin — все.

## Решения
- **FSRS-5** с параметрами по умолчанию (19 весов из открытой реализации). Целевая удерживаемость — 0,9, максимальный интервал — 365 дней. Алгоритм и его версия записываются в каждую строку истории планирования. Пересчёт — только в memory; клиент и ИИ сроки не задают.
- **Оценка ответа — правила, не ИИ.**
  - Ввод сравнивается с допустимыми ответами: перевод методиста, формы, сокращения `I'm` = `I am`, регистр и пунктуация.
  - Неверно → again. Верно после подсказки → hard. Верно выбором из готовых → hard. Верно вводом → good.
  - Детям 6–9 вместо ввода — сборка из слов или букв (верно → good, это самостоятельная сборка). Детям 10–13 — ввод, как взрослым: свободный текст детей в ИИ не идёт, сравнение локальное.
- **Карточки не плодятся.** Одна карточка на ученика, пару и лемму (или фразу). Новые источники добавляют контекст (пример), а не дубль.
- **Удержание.**
  - Проверки назначаются по событию `skills.state.changed` (`to = demonstrated`). Задания проверки — контрольные задания навыка из опубликованной версии урока; оценка — по ключам catalog в memory, без подсказок.
  - Результат — событие `memory.retention.checked.v1`. diagnostics меняет состояние: `retained`; при двух провалах подряд — `learning`.
  - Без активности 14 дней проверка откладывается, а не проваливается.
- **Чтение** — новый тип контента catalog с теми же версиями и проверкой вторым методистом. Вопросы — практика lessons `reading` с оценкой в assessment (practice_only, навыки не меняются), как упражнения к медиа.
- **Перевод по тапу.** Запрос содержит ссылку на контент (вид, id, версия, предложение), memory проверяет, что слово есть в этом тексте. Порядок поиска: словарь курса → общий кеш переводов → `teaching_coach` `gloss_word`. Ответ ИИ кешируется для всех учеников и попадает в очередь методиста; отклонённый перевод больше не показывается.
- **Произношение.**
  - Клиент пишет WAV 16 кГц моно до 15 с (Web Audio): MediaRecorder на iOS даёт AAC, который Azure не принимает в коротком REST.
  - Путь: telegram-bff проверяет согласие → memory (эталонный текст по карточке или предложению контента) → ai-gateway → Azure (REST short audio, `Pronunciation-Assessment` с `Granularity: Word`, `EnableMiscue: true`).
  - Аудио в памяти процесса не дольше запроса, в логи и события не пишется.
  - Сохраняются баллы по словам (точность 0–100, тип ошибки), общие точность, беглость и полнота, уверенность.
  - Акцент не ошибка: советы только для слов с точностью < 60 и типом `Mispronunciation` / `Omission`, не больше двух.
- **Напоминание.** memory держит проекцию часового пояса из `learning.plan.updated.v1`. Тик раз в 15 минут публикует `memory.reviews.due.v1` в местное 19:00–19:14, не чаще раза в день. Отправку, тихие часы и правила детей ведёт notifications.
- **Повторение — занятие дня.** `memory.review.completed.v1` (минуты, число заданий) → learning-plan записывает активность `review`; серия и пропуски учитывают её как практику.
- **Аналитика забывания** — агрегаты без данных учеников: по уроку и навыку — проверки 7/30 (назначено, пройдено, доля), повторные ошибки по `error_code`.
