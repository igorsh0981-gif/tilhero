# Спринт 7 — Социальное

**Цель.** Учиться вместе: друзья, лиги недели, дуэли, парные уроки с ИИ-коучем, честные рефералы и модерация. Социальное не меняет оценку языка (ARCHITECTURE п. 7): лиги и дуэли дают только игровые награды, учебное состояние меняет независимый оценщик.

**Требования LinguaFlow 1.2:**
- ученик — APP-SOC-01…10, APP-REF-01…04;
- админка — ADM-SOC-01…03, ADM-GAME-02, ADM-REF-01, ADM-REF-02;
- скиллы — `11_cooperative_lesson_coach` (LLM), `13_duel_host` (код), `14_referral_integrity_reviewer` (правила). В реестре агентов все три становятся `active`.

## Решения владельца (20.11.2026)
- **Общие лиги недели — 14+ по желанию, только ник.** Подростки 14–17 и взрослые сами включают участие. В рейтинге видны только ник, герой, XP недели, место и разрешённые значки. По умолчанию выключено. Дети 6–13 — только семейная лига, без незнакомых.
- **Парные уроки — полностью в спринте 7.** Два ученика и ИИ-коуч, у каждого своё время речи, своя оценка и свой отчёт. Минуты учитываются (сколько бы списалось), но не списываются до спринта 8.
- **Реферал засчитывается после диагностики и 3 зачётных уроков минимум в 2 разных дня.** Порог и награды задаются в админке («Реферальные кампании»). Подозрительное начисление удерживается до решения оператора. Награда пригласившему по умолчанию — 2 заморозки, как в спринте 6; лимит — 10 рефералов в месяц.

## Решения координатора
- **Лиги и дуэли — в gamification** (там XP и награды), друзья и рефералы — в social, парные комнаты и задания дуэли — в lessons. ARCHITECTURE обновлена.
- **Дуэль.**
  - Асинхронная, 48 часов на ответ, 10 закрытых заданий одной пары и уровня. Оба получают один и тот же набор, ключи проверяет сервер.
  - Время ответа на результат не влияет.
  - Ставок тилами нет: победитель получает XP, участник — XP за участие.
  - Дуэль только между друзьями 14+; детям 6–13 — только внутри семьи.
- **Парный урок.**
  - 14+ — с другом; 6–13 — только с членом семьи, режим «выбор реплик» без свободного текста.
  - Комната работает через long-poll (≤ 25 с), голос — по согласию на голос (политика 1.1+).
- **Ник** — 3–20 символов (буквы RU/UZ/EN, цифры, `_`), уникален без учёта регистра, проходит фильтр запрещённых слов. **Код друга** — 8 символов (`TH-XXXX-XXXX`), меняется по запросу.
- **Жалоба** создаёт дело модерации в social. Санкции: предупреждение, запрет социальных действий на 1–30 дней, бессрочный запрет. Решение фиксирует основание, исполнителя и срок; есть обжалование. Модератор не видит переписку и ответы без инцидента (жалоба = инцидент; виден только предмет жалобы).

## Права
- `social.read` — друзья, заявки, блокировки ученика (без переписки);
- `moderation.manage` — дела модерации, санкции, обжалования (step-up для санкций > 7 дней и бессрочных);
- `referral.read`, `referral.manage` — кампании (черновик → активация со step-up), очередь проверки: одобрить или отклонить с причиной;
- `league.read`, `league.manage` — периоды, группы, призы, аномалии, споры дуэлей, переоценка с сохранением прежней записи (step-up);
- `room.read`, `room.manage` — мониторинг комнат, остановка (step-up).

Роли:
- `support` — + social.read, moderation.manage, referral.read, room.read;
- `operations` — + все;
- `content_manager` — + league.read;
- `analyst`, `auditor` — + *.read;
- super_admin — все.

| AT-75 | Дуэль: вызов другу → принятие → оба проходят один набор → результат по серверной оценке; повтор ответа — один результат; дедлайн без ответа — техническая победа или ничья по правилам; награды один раз |
| AT-76 | Парный урок: приглашение → оба в комнате → коуч даёт роли, ходы по очереди → у каждого свои секунды речи, доказательства и отчёт; молчавший не получает оценку; выход и переподключение не создают второй сессии; переход на текст; минуты учтены, не списаны |
| AT-77 | Совместное достижение: значок «Вместе» обоим только при индивидуальном вкладе каждого; учебный mastery без вклада не меняется |
| AT-78 | Реферал: приглашён → диагностика → 3 урока в 2 разных дня → проверка → награда; самоприглашение и повтор невозможны; подозрительный — удержан, оператор одобряет или отклоняет; ученик видит статус и понятную причину отказа без правил антифрода |
| AT-79 | Жалоба на участника, приглашение или комнату → дело модерации → санкция с основанием, сроком и исполнителем → ограничение действует → обжалование → решение; история |
| AT-80 | Админка: кампании (версии, активация, лимит в месяц); лиги и дуэли (итоги один раз, переоценка сохраняет прежнюю запись, аномалии); парные комнаты (мониторинг, остановка по праву, личные оценки изолированы) |
| AT-81 | Приватность: в рейтингах только ник, герой, XP, место, разрешённые значки; ответы, ошибки, покупки не публикуются; дети не видят незнакомых |
| AT-82 | Сага удаления: друзья, заявки, блокировки, дела (обезличенно), участие в лигах и дуэлях, комнаты — удалены или обезличены |
